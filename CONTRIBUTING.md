# Contributing to @platypus/node

Thank you for your interest in contributing to the official Platypus Node.js SDK!

## Development Setup

1. **Clone the repository:**

   ```bash
   git clone https://github.com/felixkamau/platypus-node.git
   cd platypus-node
   ```

2. **Install dependencies:**

   ```bash
   pnpm install
   ```

3. **Build the package:**

   ```bash
   pnpm run build
   ```

4. **Watch mode during development:**

   ```bash
   pnpm run dev
   ```

## Pull Request Guidelines

- Open an issue first to discuss substantial architectural or breaking changes.
- Ensure TypeScript builds cleanly without errors (`pnpm run build`).
- Keep PRs focused on a single change, fix, or improvement.
- Follow existing code style and naming conventions.
